# Oliv Telegram Bot Skill

Panduan proyek untuk mengembangkan, memperbaiki, dan men-deploy Oliv Telegram Bot.

## Cara menggunakan
1. Buka file [SKILL.md](./SKILL.md) dan salin/unduh isinya.
2. Di percakapan ChatGPT baru, lampirkan file tersebut.
3. Tulis: **"Lanjutkan pengembangan Oliv Telegram Bot sesuai skill ini."**
4. Untuk coding agent yang mendukung repository skills, gunakan folder `.agents/skills/oliv-telegram-bot/`.

## Repository proyek
- GitHub: https://github.com/Rizkiihdy/keuangan-4.1
- Branch deployment: `render-free-deploy`

## Catatan
File ini adalah instruksi proyek yang bisa digunakan ulang. Menyimpannya di GitHub tidak otomatis memasang atau mengaktifkan Skill di semua akun ChatGPT.
